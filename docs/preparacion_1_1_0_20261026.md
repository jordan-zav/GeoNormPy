# Candidato GeoNormPy 1.1.0

Preparado el 26 de octubre de 2026 para su posterior publicación en PyPI.
Licencia GPL-3.0-or-later, Python >=3.9. No se creó una release ni se
ejecutó el workflow de publicación durante esta preparación.

## Consolidación

Se alinearon pyproject.toml, la versión de ejecución y CITATION.cff en 1.1.0.
Se actualizaron README, changelog y la guía de publicación. Los informes
numéricos anteriores conservan sus versiones de desarrollo e inventarios.

Se corrigió MANIFEST.in para incluir los fixtures JSON de regresión, las
pruebas, los benchmarks y la documentación de perfiles. El ejecutor
scripts/check_distribution.py comprueba licencia, versiones y recursos de
ambas distribuciones; también está conectado a CI y al workflow de publicación.

La verificación en pandas 3.1 detectó que una prueba exigía None para un
campo sin error, mientras pandas puede representarlo como NaN. La prueba
ahora usa la comprobación de ausencia de pandas, válida también en pandas 2.3.
No cambió la asignación de minerales por esa corrección.

## Comprobaciones ejecutadas

- Construcción de sdist y wheel, con el wheel construido desde el sdist.
- Revisión estricta de ambos archivos mediante twine: aprobada.
- Licencia, versión de ejecución, versión de cita y recursos de distribución:
  aprobados; no se incluyen instrucciones locales ni archivos de autenticación.
- Entorno limpio: Python 3.11.9, NumPy 2.4.6, pandas 3.1.0 y PyYAML 6.0.3.
- Suite completa ejecutada desde el sdist extraído, fuera del repositorio:
  388 pruebas aprobadas en 26,12 segundos, ninguna omitida.
- Incluye la prueba del wheel real para los tres perfiles.
- La prueba corregida de lotes también pasa en el entorno anterior con pandas 2.3.

La matriz de CI está configurada para Python 3.9, 3.11 y 3.14; no se afirma
una ejecución local de las versiones 3.9 y 3.14.
